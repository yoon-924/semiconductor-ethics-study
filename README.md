# 반도체 윤리 학습실

모바일 우선 HTML 학습 사이트. 정리본 / 객관식 퀴즈 / 학습가이드 3개 메뉴.

- 7대단원·21챕터 정리 카드
- 4지선다 549문항과 함정 OX 37개
- 보기 섞기, 답 확정 후 확신도, 즉시 채점·근거 쪽수
- 오답 3문항 뒤 재출제, 정답 3→10→40시간 복습
- 기기별 localStorage 기록, JSON 백업·복원
- 이미 학습한 문제로만 모의고사 최대 42문항
- 첫 온라인 접속 후 서비스워커를 통한 오프라인 사용
- 라이트/다크, 375px 모바일, 키보드와 reduced-motion 대응

원본 PDF와 개인 진도 파일은 이 저장소에 올리지 않습니다. 자동 기기 간 동기화는 없으며 기록 백업·복원으로 옮깁니다. 자료 Quiz의 원문 단답형은 객관식으로 변환했으며 실제 시험 기출 여부는 확인되지 않았습니다.

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root) → Save.

## 파일
`index.html`은 모든 학습 데이터·스타일·퀴즈를 포함한 단일 HTML입니다. `sw.js`, manifest와 아이콘은 홈 화면 추가·오프라인 사용을 지원합니다. 별도 빌드나 외부 패키지는 없습니다.
